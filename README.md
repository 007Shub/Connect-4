# Connect 4

A classic Connect 4 game which people play In real life also. Two players take turns dropping
pieces into a 7-column board ,where first to get 4 in a row wins!

## Play it online

 **https://007shub.github.io/Connect-4/**

Type a column number (1–7) and press Enter to drop your piece.

- 🟡 Player 1 = Yellow
- 🔴 Player 2 = Red

## 🛠️ Built with

- **C** – the game logic
- **Emscripten** – compiles the C code to WebAssembly so it runs in a browser
- **xterm.js** – shows the game in a terminal on the web page
